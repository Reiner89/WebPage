# WILLS E-commerce

Proyecto frontend sin backend, usando HTML, Tailwind CDN y JavaScript puro.

## Rutas

- `#/` Home
- `#/shop` Listado
- `#/product/1` Detalle de producto
- `#/cart` Carrito
- `#/checkout` Checkout
- `#/about` Nosotros
- `#/help` Centro de ayuda

## Cómo abrir

Abre `index.html` en el navegador.

Si el navegador bloquea módulos JS por abrirlo directo, usa un servidor local:

```bash
python -m http.server 5500
```

Luego entra a:

```txt
http://localhost:5500
```
